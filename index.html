How a project runs

Four steps, no surprises. You always know what's happening and what's next.

  1. Discover

    We agree the goal, the audience and the one action the site has to drive. An hour here saves a week of fixing the wrong thing.

  2. Design

    Layout and type first, in the browser where possible, so what you approve is what ships.

  3. Build

    Hand-written HTML, CSS and JavaScript. Mobile first, keyboard friendly, quick on a mid-range phone.

  4. Launch & support

    Deployed with security headers and structured data in place, then I stay on for fixes and changes.
